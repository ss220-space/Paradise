code/game/atom/atom_color.dm

Atom Colour Priority System A System that gives finer control over which atom colour to colour the atom with. The "highest priority" one is always displayed as opposed to the default of "whichever was set last is displayed"

It can also be used for color filters, since some effects (using non-RGB space matrices) are impossible to achieve with just the color variable
