Proc Details

proc
apply_nested_contents
(/obj/item/storage/parent_storage, container_key, parent_path)

Fills an in-world storage item with the edited contents configured for it, replacing any preset (populate_contents) items. Does nothing if the box has no explicitly configured contents, so untouched boxes keep their presets. Arguments:

  • parent_storage - the storage item instance just spawned.
  • container_key - "backpack" or "belt".
  • parent_path - the storage item's type path in string form.

proc
capture_nested_contents
(/obj/item/storage/parent_storage, container_key)

Captures the contents of a storage item already worn (inside backpack/belt) into the nested storage map so it can be edited in the UI. Arguments:

  • parent_storage - the storage item inside the container.
  • container_key - "backpack" or "belt".

proc
decrement_list_entry
(/list/storage_list, item_path)

Decrements one item of the given path in a path = count list. Arguments:

  • storage_list - list(path = count) to remove from.
  • item_path - type path of the item to remove.

proc
ensure_check_dummy
(/mob/living/carbon/human/human)

Ensures a clean dummy human of the given human's species exists for can_equip-based checks.

proc
ensure_nested_presets
(container_key, storage_path)

Initializes the nested contents of a storage item added to a container from its own preset (populate_contents) items, so the box's contents can be viewed and edited right away. Only seeds the entry once per box path. Arguments:

  • container_key - "backpack" or "belt".
  • storage_path - the storage item's type path.

proc
forget_nested_contents
(container_key, parent_path)

Removes the nested contents entry for a storage item that was just removed from a container. Arguments:

  • container_key - "backpack" or "belt".
  • parent_path - the removed storage item's type path in string form.

proc
get_preset_mod_back_contents
(mod_path)

Adds the preset bag contents of a MOD control unit type to the outfit backpack list (path = count).

proc
get_preset_storage_contents
(storage_path)

Returns the preset contents of a storage item type - populate_contents() as a list(path = count). Arguments:

  • storage_path - type path of the storage item to inspect.

proc
item_fits_species

proc
remove_nested_storage_item
(container_key, parent_path, item_path)

Removes one item from the contents of a nested storage. Arguments:

  • container_key - "backpack" or "belt".
  • parent_path - the parent storage item's type path in string form.
  • item_path - the item type path to remove.

proc
serialize_container
(container_key, /list/contents)

Builds the UI item list for a storage container, embedding each nested storage item's own contents (one level deep). Arguments:

  • container_key - "backpack" or "belt".
  • contents - the container's flat list(path = count).

proc
serialize_nested
(container_key, parent_path)

Serializes the contents of a single nested storage item as a UI item list. Arguments:

  • container_key - "backpack" or "belt".
  • parent_path - the parent storage item's type path in string form.
