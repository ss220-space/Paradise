swarmer
/obj/structure/swarmer

Swarmer structures

Has 4 different interactions based on swarmer's intent, separated in swarmer_act(). All structures of this type allow swarmer projectiles to pass through them.

projectiles_passDo we let swarmer projectiles pass through

Procs

swarmer_harm_actSpecial intent handling for swarmer clicks on swarmer structures. Used by builders for destroying.
swarmer_help_actSpecial intent handling for swarmer clicks on swarmer structures. All structures are not interactable, if unanchored.
